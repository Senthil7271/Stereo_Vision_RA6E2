=================================================================
RENESAS FPB-RA6E2 STEREO VISION & COLLISION RADAR DATASET (32GB SD)
=================================================================

DIRECTORIES:
  /STEREO/   -> 128x128 Raw 8-bit Grayscale Binary Images (16 KB each)
  /STEREO64/ -> 64x64 Raw 8-bit Grayscale Binary Images (4 KB each)

FILE NAMING:
  L0000.BIN = Left Camera Frame 0
  R0000.BIN = Right Camera Frame 0
  ...
  Total Frames: 10

INSTRUCTIONS:
  1. Format your 32 GB Micro SD card as FAT32.
  2. Copy the STEREO folder, STEREO64 folder, and CONFIG.TXT directly to the root of the SD card.
  3. Insert the Micro SD card into the SPI adapter connected to FPB-RA6E2.
